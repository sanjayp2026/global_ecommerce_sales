# Global E-commerce Sales Analysis

## Overview

A small e-commerce sales analysis project created using Microsoft Excel.

The project focuses on organizing and analyzing sales data to understand overall sales performance and identify useful business insights.

## Tool Used

- Microsoft Excel

## Analysis

The project uses Excel for:

- Organizing sales data
- Basic data analysis
- Sales performance analysis
- Comparing sales across available categories
- Summarizing key sales information

## Project File

| File | Description |
|---|---|
| `Global_Ecommerce_Sales_Analysis.xlsx` | Excel workbook containing the e-commerce sales analysis |

## Key Learning

This project helped me practice using Microsoft Excel for basic data analysis and understand how sales data can be used to identify meaningful insights.
